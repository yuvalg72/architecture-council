# Changelog

All notable changes to the ChatGPT Architecture Council Skill are documented here.

## [1.0.0] - 29/07/2026

### Added

- Native ChatGPT Skill structure with `SKILL.md` and `agents/openai.yaml`.
- Professional executive and architecture reviewer roles.
- Quick Council, Duo Review, and Full Council modes.
- Problem restatement, independent opening positions, challenge rounds, final stances, weighted tally, minority preservation, kill criteria, and outcome tracking.
- Honest single-model structured deliberation fallback for environments without isolated agents.
- Decision dossier and decision record validation scripts.
- Security and provider controls for internal and customer-sensitive information.
- Controlled integration boundary with the future `lessons-learned` Skill.
- Optional legacy compatibility with the original 18 analytical lenses.

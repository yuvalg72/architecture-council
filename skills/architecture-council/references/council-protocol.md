# Council Protocol

1. Ground the question with a validated Decision Dossier.
2. Select Quick, Duo, or Full mode.
3. Select reviewers before positions exist.
4. Restate the problem through each lens.
5. Produce independent opening positions.
6. Challenge assumptions and require self-correction.
7. Record a protocol intervention only when corrective work is required outside the normal mode-defined flow. Classify each corrective pass under exactly one primary category: `insufficient_dissent`, `novelty_failure`, `premature_consensus`, `missing_stance`, or `evidence_gap`. Normal challenge rounds are not interventions.
8. Record final stances in the required machine-readable format.
9. Calculate confidence-weighted support.
10. Preserve the strongest minority case and unresolved questions.
11. Let the Independent Chairman synthesize without voting. Protocol intervention counts are process-quality context and never additional vote weight.
12. Define observable kill criteria and exactly one next action.
13. Record a prediction and review checkpoint before acting.

For structured Decision Records, new records use schema version `1.1`. The intervention `total` equals the sum of the five category counts. This deliberately measures corrective protocol events rather than model calls, provider dispatches, or normal deliberation steps.

Do not use deliberation to decorate a decision already made.
